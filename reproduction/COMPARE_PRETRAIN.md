# 训练前后交互续写对比

在 VS Code 按 Ctrl+Shift+D，选择 **04 训练前后交互续写对比**，按 Ctrl+F5。
初始化完成后，在集成终端的 `请输入开头 >` 后输入文本并回车，同一段文本会分别交给随机初始化模型与本次试跑权重续写，输出会流式显示。

可以输入：

```text
今天早上，我打开窗户，看到
机器学习是一种
问：植物为什么需要阳光？
```

也可以输入 `/examples` 运行固定的三个提示，`/exit` 退出。每次输入独立处理，不保留聊天历史。
预训练阶段使用 BOS + 原始文本续写，不应用 SFT 对话模板。即使输入问题，当前也只是续写，不保证遵循指令或回答正确。

## 对照条件

- 两个模型结构相同，使用相同 tokenizer、设备、推理精度、输入 token 和生成上限。
- 训练前基线按当前代码和 seed=42 重建。最初训练前没有单独保存权重，因此不能把它当成经原始快照逐位校验的训练前模型；未来正式实验建议提前保存初始快照。
- 训练后严格加载 `out/smoke/pretrain_smoke_768.pth`。完成正式预训练后，可以在 launch.json 第 04 项中修改 `--weight` 为 `out/pretrain_768.pth`。
- 默认贪心生成，不做随机采样；要体验采样，把 `--mode` 改为 `sample`。此时每个模型生成前都重设相同种子。
- `temperature`、`top_p`、`top_k` 只在 sample 模式生效。`max_new_tokens` 是新生成 token 的上限，不是字数。
- 为观察模型本来的输出，默认 repetition_penalty=1.0，不额外抑制重复。greedy 模式下未经充分训练的模型可能反复输出同一片段，这也是观察结果。

每组结果自动追加到 `out/comparisons/<时间>.jsonl`，包括输入、实际输入 token、两边输出 token 和文本、种子、设置、环境版本及训练后权重 SHA256。该目录位于被忽略的 out 内，不会自动提交个人输入。

命令行也可重复执行固定比较，例如：

```text
python scripts/compare_pretrain.py --examples
python scripts/compare_pretrain.py --prompt "机器学习是一种" --max_new_tokens 32
```

脚本内的数据与权重相对路径基于项目根目录解析；这一点与原 trainer 脚本依赖 cwd 的方式不同。

## 如何判断

观察生成字符是否可读、是否形成词句、是否关联提示、是否重复和是否过早结束。随机模型可能输出随机字符，也可能因共享输入输出嵌入而反复输出提示末尾片段。

本次只训练 128 条、64 步，训练后也可能仍然重复、不通顺或无法回答问题。不要仅凭几个生成样例判断训练失败或宣称能力提升；训练 Loss、独立验证集指标和固定提示结果应结合评估。
固定提示用于演示，尚未做训练集重合检查，不是严格保留的测试集。下一步正式比较需建立独立评测集。

此工具只运行推理，不更新参数，也不修改已有权重。SFT 完成后的多轮聊天应另用相应对话模板入口。
